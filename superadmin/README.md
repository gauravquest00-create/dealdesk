# DealDesk SuperAdmin Portal

Dedicated platform operations and multi-tenant management portal for DealDesk administrators.

## Features
- **Global Platform Metrics**: Live Monthly Recurring Revenue (MRR), Active Workspaces, Trial Conversions, and Payment Failures.
- **Customer Business Management**: Business lifecycle management, detailed accounts, user oversight, and reason-mandated account suspension.
- **Controlled Support Access Mode**: Temporary, reason-bound customer workspace troubleshooting with audit logging and visible countdown banner.
- **Subscriptions & Payments**: Platform-wide transaction ledger and tier configurations.
- **Audit Logs**: Comprehensive audit trail of all sensitive operator actions.

## Development
```bash
npm install
npm run dev # Runs on http://localhost:5174
```

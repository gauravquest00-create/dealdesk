# DealDesk Dashboard Application

Complete operational deal workspace for real estate brokerages with dual Admin and Agent personas, role-based access control, PWA support, dynamic QR resolver, and Smart Match engine.

## Features
- **Dual Persona RBAC**: Admin full business snapshot vs. Agent assigned-only data isolation.
- **Smart Deals Workspace**: Properties, Smart Leads, 7-factor Match, Viewings, Open House, Smart QR, Documents, Communications, Deals pipeline, Team.
- **Dynamic Smart QR**: QR resolver with fallback replacement inventory for sold properties.
- **Viewing Reports**: Structured feedback capturing with automatic lead score and temperature recalculation.
- **PWA Ready**: Mobile-first bottom navigation, offline service worker, installable standalone web application.
- **Central API Client**: Dynamic API configuration via `VITE_API_BASE_URL`.

## Development
```bash
npm install
npm run dev # Runs on http://localhost:5173
```

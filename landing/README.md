# DealDesk Landing & Acquisition Website

Public-facing acquisition portal, marketing pages, pricing calculator, i18n localization, 3-Day Free Trial signup, and 6-step Onboarding flow for DealDesk.

## Features
- **Dynamic Pricing Engine**: Instant currency conversion (USD, CAD, GBP, AED, AUD, EUR, INR) & annual billing toggle.
- **Internationalization (i18n)**: Multi-language architecture (English, Arabic, French, Spanish, German).
- **6-Step Interactive Onboarding**: Seamless transition from trial signup to fully configured workspace.
- **Central API Client**: Decoupled network layer using `VITE_API_BASE_URL`.
- **Responsive & Accessible**: Strict 320px-1920px responsiveness without card-in-card nesting.

## Development
```bash
npm install
npm run dev # Runs on http://localhost:5175
```
